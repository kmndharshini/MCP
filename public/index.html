Google Workspace MCP

Operational

This serverless Model Context Protocol (MCP) server is live on Vercel. It exposes secure, user-delegated Google Workspace tools to AI assistants via Server-Sent Events (SSE).

Available Tools
send_email
Sends plain-text emails via the authenticated Gmail account.
append_to_google_doc
Appends text to the end of a Google Doc using the Google Docs API.
SSE Connection URL
https://<your-project>.vercel.app/sse?key=YOUR_MCP_API_SECRET
